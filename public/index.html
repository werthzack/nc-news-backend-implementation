Article API Documentation

Welcome to the Article API reference. This guide provides detailed explanations, request formats, query parameters, and example responses for each available endpoint. The API is organized by resource: Topics, Articles, Comments, and Users.

Topics — GET /api/topics

Retrieve a list of all available discussion topics. Topics categorize articles across the platform.

Example Request

GET /api/topics

Example Response

{
  "topics": [
    { "slug": "sports", "description": "Covers global sporting news" },
    { "slug": "cooking", "description": "Food, recipes, and culinary tips" }
  ]
}

Articles — List Articles

Retrieve all articles, sorted by creation date by default. Each article includes metadata such as author, topic, votes, and comment count.

Example Request

GET /api/articles

Example Response

{
  "articles": [
    {
      "article_id": 1,
      "title": "First Article",
      "topic": "sports",
      "author": "john",
      "votes": 10,
      "comment_count": 4
    }
  ]
}

Articles — Filter & Sort

You can filter the article list using the following query parameters:

  • topic — Filter by topic (e.g., ?topic=sports)
  • sort_by — Sort by any valid column (e.g., ?sort_by=votes)
  • order — asc or desc (e.g., ?order=asc)

Example Request

GET /api/articles?topic=sports&sort_by=votes&order=desc

Articles — Retrieve Article

Fetch a single article using its unique article_id. The response includes the full article body.

Example Request

GET /api/articles/1

Example Response

{
  "article": {
    "article_id": 1,
    "title": "First Article",
    "topic": "sports",
    "author": "john",
    "body": "This is an article about sports.",
    "votes": 10,
    "created_at": "2024-01-01"
  }
}

Articles — Comment Count

Retrieve an article along with the total number of comments made on it. Useful for displaying article statistics.

Example Response

{
  "article": {
    "article_id": 1,
    "title": "First Article",
    "comment_count": 4
  }
}

Articles — List Comments

Retrieve all comments belonging to a specific article.

Example Response

{
  "comments": [
    { "comment_id": 1, "author": "jane", "body": "Great article!" },
    { "comment_id": 2, "author": "mark", "body": "Very informative." }
  ]
}

Articles — Create Comment

Add a new comment to an article by providing an author and comment body.

Request Body

{
  "author": "jane_doe",
  "body": "Loved this article!"
}

Example Response

{
  "comment": {
    "comment_id": 3,
    "author": "jane_doe",
    "body": "Loved this article!",
    "created_at": "2024-03-01"
  }
}

Articles — Update Article

Update the vote count of an article. Pass a positive or negative integer to increase or decrease votes.

Request Body

{
  "inc_votes": 3
}

Example Response

{
  "article": {
    "article_id": 1,
    "votes": 13
  }
}

Comments — Delete Comment

Delete a specific comment using its comment_id. Returns no content.

Example Request

DELETE /api/comments/5

Response

Status: 204 No Content

Users — List Users

Retrieve all registered users. Users may appear as authors of articles or comments.

Example Response

{
  "users": [
    { "username": "john", "name": "John Doe" },
    { "username": "jane", "name": "Jane Smith" }
  ]
}
